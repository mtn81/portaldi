# レビューの観点

レビューを依頼されたときは、以下の観点でフィードバックする:

- コード品質とベストプラクティス
- 潜在的なバグや問題
- パフォーマンスの考慮点
- セキュリティ上の懸念
- テストカバレッジ
- ドキュメントに内容が反映されているか
- CLAUDE.md の「開発時の規約」と `.claude/rules/` の規約に従っているか

レビュー結果は、建設的で役立つ内容を心がける。
